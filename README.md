# FreelancePRO

Freelance-company matching platform built with PHP/MySQL.

**Features**:
- Admin: Complete dashboard
- Company: Post job offers
- Freelancer: Apply to projects

**Quick Setup**:
1. Import database (`freelancepro.sql`)
2. Configure `includes/db.php`
3. Run on localhost

**Tech Stack**: PHP, MySQL, HTML/CSS, JavaScript
